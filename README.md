# Red Crescent Operational Plan Analytics

## Project Overview

An interactive Power BI dashboard developed to monitor the operational plan, strategic objectives, performance indicators, goal ownership, and planned achievement rates.

The dashboard helps management track objectives across departments, months, and quarters to support performance monitoring and data-driven decision-making.

## Business Objectives

- Monitor the progress of the operational plan.
- Track strategic and departmental objectives.
- Analyze planned performance rates.
- Evaluate objectives by month and quarter.
- Monitor performance indicators and measurement types.
- Identify goal owners and responsible departments.
- Support management with clear performance insights.

## Key Metrics

- Number of Strategic Objectives
- Number of Department Objectives
- Number of Performance Indicators
- Number of Goal Owners
- Number of Monthly Records
- Planned Achievement Rates

## Dashboard Features

- Strategic objective tracking
- Department-level objective analysis
- Monthly and quarterly performance monitoring
- Goal-owner analysis
- Performance indicator analysis
- Interactive filters and slicers
- Clear KPI cards and management visualizations

## Tools and Technologies

- Microsoft Power BI
- Power Query
- DAX
- Data Modeling
- Data Cleaning
- KPI Reporting
- Data Visualization
- Business Intelligence
